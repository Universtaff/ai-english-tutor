# English Tutor · Gia sư tiếng Anh

**▶ Dùng thử / Try it:** https://universtaff.github.io/english-tutor/

## Tiếng Việt

Gia sư tiếng Anh AI tên **Sam**: một nhân vật anime 3D gọi thoại với bạn như FaceTime, mấp máy môi theo giọng nói, luyện nói IELTS mỗi ngày.

- **Gọi thoại trực tiếp** với Sam (Gemini Live), có phiên âm cả hai bên.
- **Luyện IELTS:** thi thử Speaking Part 1-2-3, chấm Writing theo 4 tiêu chí, lộ trình 40 bài từ band 5 lên 8.
- Nói chen tiếng Việt cũng được, Sam hiểu và gợi ý cách nói bằng tiếng Anh.
- Cảnh nền tiên cảnh đổi theo buổi, thời tiết thật và mùa của khu vực bạn chọn.
- **Miễn phí:** dùng khoá Gemini API gói free của chính bạn, lưu trên máy bạn, không gửi đi đâu khác.
- Cài lên điện thoại: mở link → menu trình duyệt → "Thêm vào màn hình chính".

## English

An AI English tutor named **Sam**: a 3D anime character you video-call like FaceTime, with lip-sync to her voice, built for daily IELTS speaking practice.

- **Live voice calls** with Sam (Gemini Live), with transcripts for both sides.
- **IELTS practice:** Speaking Part 1-2-3 mock tests, Writing scored on the 4 official criteria, a 40-lesson path from band 5 to 8.
- Background scene follows the time of day, real weather and season for your chosen region.
- **Free:** uses your own free-tier Gemini API key, stored only on your device.
- Install on your phone: open the link → browser menu → "Add to Home screen".

## Chạy trên máy / Run locally

```
python -m http.server 8767
```

Mở / open http://localhost:8767 — không cần build / no build step.
